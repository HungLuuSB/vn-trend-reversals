The daily price data that support the findings of this study are available from CafeF and Yahoo
Finance. Restrictions apply to the availability of these data, which are not redistributed with
this article. The VIX and US Treasury yields are publicly available from the Federal Reserve Bank of
St.\ Louis (FRED), and the daily geopolitical risk index from \citet{CaldaraIacoviello2022}. The
extracted non-performing-loan ratios, the analysis code, the dated decision record and the
configuration of every run are available from the corresponding author upon reasonable request.
All results come from one frozen data snapshot (identifier \gen{SnapshotId}) and the code at commit
\gen{FinalCommit}, from which the full dataset can be rebuilt.
